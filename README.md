# Веб-приложение Yatta
**Демо:** [http://31.56.48.231](http://31.56.48.231)

## Описание проекта

Yatta — это веб-приложение для изучения японского языка с системой администрирования.

Проект включает:
- Аутентификацию (регистрация, вход, личный кабинет)
- Учебные материалы (структурированные уроки, упражнения)
- Отслеживание прогресса (статистика изученного)
- Админ-панель (управление пользователями и контентом)

## Стек технологий

| Категория       | Технологии                     |
|----------------|-------------------------------|
| **Backend**    | Django (Python)               |
| **База данных**| SQLite, PostgreSQL                   |
| **Frontend**   | HTML, CSS (SASS), JavaScript |
| **Деплой**     | Docker                      |


## Ключевые особенности

✓ Полноценная система пользователей с ролями (ученик/администратор)  
✓ Гибкая модель базы данных для хранения учебных материалов и прогресса  
✓ Система достижений - геймификация обучения  
✓ Масштабируемая архитектура для возможного расширения  

## Возможные сценарии использования

- Онлайн-курсы японского языка
- Платформа для языковых школ с возможностью администрирования
- Базовый каркас для аналогичных образовательных проектов
